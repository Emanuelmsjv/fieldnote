# Offline transcription of field notes: measured results

Generated by `npm run eval:compare`.

## Headline

**Scaling the model made the domain vocabulary worse.** `base` is the larger model and recovers 48.5% of bird-name tokens; the smaller `tiny` recovers 54.5%. Corpus word error rate also got worse, from 9.6% to 11.3%.

Both are Whisper checkpoints at the same quantisation, differing only in size. Buying a
bigger general-purpose model does not buy you a regional bird vocabulary.

Ordinary speech is transcribed perfectly by every model tested. The difficulty is specific:
multi-syllable compound names that do not occur in general English training data.

## Why this matters for the design

If transcription of bird names were reliable, a spoken field note could be trusted as data.
It is not, so this project treats every transcript as a draft:

1. The transcript is always shown to the user, never hidden.
2. Extracted species are matched against the local species list and anything unmatched is
   flagged rather than silently dropped or silently accepted.
3. Corrections the user makes are kept, and exported as a fine-tuning corpus.

Step 3 is only possible with open weights. A cloud speech API cannot be fine-tuned on
Chidambaram bird vocabulary, and it would require shipping audio off the machine to do it.
That is the argument this project is making, and the numbers above are the evidence.

## Method

Audio fixtures are generated deterministically from `data/eval/sentences.json` using the
Windows SAPI voice, so the set is regenerable and the audio is committed. Categories:
`ordinary` is plain everyday speech, `species` is dominated by bird names, `mixed` is
field-note phrasing with numbers and place names.

Word error rate is standard Levenshtein over whitespace tokens after lowercasing, punctuation
stripping and expanding digits to words. Bird-name recovery is a bag-of-words check of whether
each bird-name token in the reference appears anywhere in the transcript, which catches the
specific failure where a name is not mispronounced but dropped or split.
